# 策划数据面板:人设、核心档案、网关世界书

打开 **http://127.0.0.1:18080/panel**(手机开着 Tailscale 时是 `http://dafeiyu:8080/panel`),用 `.env` 里的 `GATEWAY_PANEL_PASSWORD` 登录。这个密码只管面板,和设备 Token 无关。改动下一轮就生效,不用重启。

查看密码:`grep '^GATEWAY_PANEL_PASSWORD=' ~/dafeiyu/.env`

## 人设 / 核心档案

- **人设**:大肥鱼是谁、怎么说话,放在系统提示最前面。
- **核心档案**:关于你的关键事实,每一轮都带上,不靠检索;召回块里写着「事实冲突时以核心档案为准」。

也可以直接用编辑器改 `data/gateway/persona.md`、`data/gateway/core_profile.md`。

## 网关世界书

和酒馆(SillyTavern)的世界书是同一种格式:

- 酒馆里导出的世界书 JSON,在面板「世界书 → 导入酒馆 JSON」导进来就能用;面板「导出」的文件也能导回酒馆,酒馆特有的字段不会丢。
- 匹配规则和酒馆一样:主关键词(逗号分隔,`/正则/` 也行)、次关键词 + 逻辑(与任一 / 与全部 / 非任一 / 非全部)、常驻、停用、概率、扫描深度、区分大小写、整词、互斥组、递归、顺序、预算。
- 每轮往回看最近 2 条消息(含你这一句,可在「世界书设置」改),命中的条目放进召回块的「相关条目」一节。**记忆库挂了的降级轮也照样注入。**
- 和酒馆不同的地方:网关没有角色卡、作者注释、示例对话,所以「插入位置 / 深度 / 角色」不起作用,所有条目都进「相关条目」;粘性、冷却、延迟、角色过滤也不起作用。这些字段原样保留。
- 「试匹配」:贴一段对话,看哪些条目会被注入、按什么顺序。

世界书文件在 `data/gateway/worlds/<名字>.json`,全局设置在 `data/gateway/lore_settings.json`。

## 版本与回滚

每次保存都会留一个版本;直接改文件也会在下一次读取时自动补记一版(来源显示「直接改文件」)。每一页都有「历史版本」,可以查看任何一版并回滚。删掉的世界书也能从历史里找回来。版本存在 `data/gateway/curated.sqlite3`。
