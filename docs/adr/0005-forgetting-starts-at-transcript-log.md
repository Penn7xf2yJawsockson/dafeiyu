# 遗忘从原文日志做起,抹除会绕过 Ombre-Brain 的不删除原则

原文日志是唯一真源,两个记忆库可以从它重放重建(ADR-0001),所以只在记忆库里删除的内容,下次重建时会回来。遗忘因此一律先在原文日志上标记或删除,再传到两个库。我们提供两档:隐藏(默认,可撤销)和抹除(不可撤销,需二次确认)。不做「不记录的临时通道」,所有对话先记下,事后再遗忘。

## Consequences

- Ombre-Brain 刻意不提供物理删除:MCP、REST、Dashboard 的「删除」都只是移入 `archive/`。抹除要由网关绕过 Ombre,直接删除它的 Markdown 文件和 `_sources/` 原文证据,然后重建 Ombre 的索引。以后升级 Ombre 时要确认这条路径仍然可用。
- 抹除要覆盖五处:原文日志、Hindsight(`delete_document` 后不含该轮重新 retain)、Ombre 记忆文件、Ombre 原文证据、网关审计记录。如果 Ombre 开了 GitHub 同步,远程仓库的历史提交里还会留有原文,抹除后要提醒用户另行处理。
