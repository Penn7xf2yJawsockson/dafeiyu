# 原文日志是唯一真源,两个记忆库只是派生索引

Hindsight 不保存原文("The content itself is never stored verbatim"),漏抽取的细节会永久丢失;Ombre-Brain 会合并相似记忆(merge_threshold 75)并按衰减曲线自动归档。两者都不能单独充当持久保证。因此每一轮原文先写入我们自己的原文日志,再投递给两个记忆库;库损坏、漏写或换库时都从原文日志重放重建。

## Consequences

- "100% 保证"严格只覆盖执行保证与持久保证;相关性保证依据两库文档(Ombre 自述召回门是已知设计债、Hindsight 分数为相对值)明确不承诺,只要求可审计。
- 关键事实不走检索,以核心档案形式每轮确定性注入。
